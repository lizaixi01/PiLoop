## 发现与修复

- 全局命令读取的 `lib` 曾仍是旧编译产物；在真实安装环境重新安装依赖并构建后，从桌面运行全局 `piloop` 验证原生 TUI。`/example` 已验证向系统浏览器提交本地 HTML 预览并返回就绪；命令行为另有注入式测试。

- 默认 npm 缓存写入受限，开发安装使用工作目录内缓存。
- 本机 4310 端口由 QQ 使用；改为 4510/4511，不停止其他应用。
- 默认凭据路径可能需要创建外部锁文件；PiLoop 使用独立本地配置，复用 Pi 配置需显式指定路径。
- Playwright 的 service worker 屏蔽注入在 sandbox 页面产生自身错误；移除该注入，通过预览 CSP 禁止 worker，并在截图后汇总错误，避免错误与通过标志不一致。
